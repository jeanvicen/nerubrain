# Roadmap

## Available in this alpha
- Dependency-free SWC parsing and summary of local files.
- Conservative morphology checks and backend-neutral network/simulation contracts.
- Provenance-aware NeuroMorpho.org standardized CNG SWC sample and downloader.
- Unit tests for parser, metadata URL safety, and declared data models.

## Not implemented
- A simulation engine or Brian2/NEURON adapter.
- Biophysical parameter inference, scientific prediction, or model validation.
- General-purpose morphology analytics, visualization, or automated repair.

## Next
1. Add checked, provenance-documented examples with redistributable terms.
2. Expand structural validation and property-based fixtures without treating it as biological QA.
3. Prototype a real simulator adapter only with version-pinned dependencies, reference cases, and independently documented scientific validation.
